# Data model

## Reference

The saved conceptual object: an image, post, page, file, or frame.

## Asset

The file object: original image, thumbnail, preview, dimensions, hashes, colors.

## Source snapshot

The captured context: URL, page title, selected text, post text, metadata blob.

## Board

A hand-curated grouping.

## Tag

A reusable label for search and filtering.

## Rule

A post can contain many assets. An asset belongs to one reference. A reference can belong to many boards and tags.
